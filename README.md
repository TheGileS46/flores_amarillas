# Flores para ti 💛

Un pequeño paseo 3D hecho con Three.js como regalo romántico.

## Cómo jugar

- En computadora: arrastra el mouse sobre la escena para caminar, o usa `WASD` / las flechas. Pulsa `E` / `Espacio` para recoger.
- En celular: mueve el joystick virtual o desliza un dedo sobre la escena. Toca **recoger** cuando aparezca una flor cerca.
- Encuentra las 6 flores amarillas para preparar el ramo.

## Publicarlo en GitHub Pages

Este proyecto no necesita compilación ni servidor. Sube los archivos del repositorio y activa GitHub Pages usando la rama principal y la carpeta raíz (`/`). La página usa Three.js y las fuentes desde CDN, por lo que el dispositivo necesitará conexión a internet al cargarla.
